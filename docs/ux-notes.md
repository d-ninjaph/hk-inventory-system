# UX Notes

## Staff Tablet App

The tablet app should be simple enough for non-technical staff to learn quickly.

Design rules:

- Large touch targets.
- Minimal typing.
- Plain language.
- Clear offline/sync status.
- Dine-in/take-out selection always visible during ordering.
- Do not expose recipe or costing complexity to staff.
- Use confirmation for voids, cancellations, and day closing.

Primary screens:

- PIN login
- Start day
- Orders
- Inventory
- Alerts
- End day
- Sync

## Owner Web Dashboard

The dashboard handles setup and review work.

Primary screens:

- Login
- Home/status overview
- Menu items
- Inventory items
- Recipes/ingredients used
- Packaging rules
- Low-stock settings
- Reports
- Sync status

## Branding Direction

- Use Hong Kong red, menu yellow, black, and white.
- Keep operational screens cleaner than the printed menu standee.
- Use brand colors for headers, selected states, primary actions, and alerts.
- Avoid heavy patterns behind forms or order buttons.
