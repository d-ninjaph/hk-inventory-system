# Accounts And Tools

## Required Now

- GitHub account: already available for the repository.
- Google account: needed for Firebase project ownership.

## Required Before Cloud Setup

Create a Firebase project using the Google account.

Enable:

- Firebase Authentication
- Firestore Database
- Firebase Hosting

Recommended Firebase project name:

```text
hk-inventory-system
```

Recommended first Firebase web app name:

```text
owner-dashboard
```

After creating the web app, copy the Firebase config values into:

```text
apps/web-dashboard/.env
```

Use:

```text
apps/web-dashboard/.env.example
```

## Required Before Tablet App Development

Install:

- Flutter SDK
- Android Studio
- Android SDK

Accounts:

- No Google Play Developer account is required for Phase 1 if the APK is installed directly on the tablet.
- A Google Play Developer account is only needed later if the app will be distributed through the Play Store.

## Optional

- Claude Design: UI/UX ideation.
- Figma: design cleanup and clickable mockups.
- Google Drive: shared client forms and data collection sheets.
