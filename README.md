# Franchise Inventory System

Phase 1 system for an offline-first food cart ordering and inventory workflow.

## Apps

- `apps/tablet-app` - Android tablet app for staff operations.
- `apps/web-dashboard` - Owner/admin web dashboard for setup, monitoring, and reports.

## Phase 1 Focus

- Offline order taking
- Dine-in and take-out handling
- Menu modifiers and add-ons
- Inventory deduction from configured recipes
- Stock-in, wastage, spoilage, and adjustment records
- Low-stock alerts
- End-of-day inventory and sales reports
- Cloud sync for owner visibility

## Stack

- Tablet app: Flutter + local SQLite
- Web dashboard: React + Vite
- Cloud: Firebase Auth, Firestore, Firebase Hosting
